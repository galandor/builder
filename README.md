# Строим дом

Интерактивная презентация детской строительной игры для трёх лет. Ребёнок выбирает дом, слышит вопрос и нажимает нужную машинку. Верная машинка сама делает этап. Неверная подпрыгивает и говорит «Я так не умею».

Открыть плоскую презентацию: https://galandor.github.io/builder/

Объёмная версия лежит в ветке `3d`, файл `preview/3d.html`. Дома, кирпичи и машинки там собраны из объёмных фигур. Локально: `python3 -m http.server 8765` и открыть http://127.0.0.1:8765/preview/3d.html

## Как играть

1. Выбрать один из трёх домов: жёлтый с красной крышей, голубой с коричневой или розовый с синей.
2. На площадке отвечать на вопрос нужной машинкой.
3. В конце дом стоит на серой дорожке. Кнопка «Построить ещё» возвращает к выбору.

Вопрос всегда написан на экране. Кнопка с динамиком повторяет его. Звук включается с первого нажатия: его читает русский голос браузера.

## Этапы

1. Бульдозер расчищает площадку.
2. Самосвал увозит мусор.
3. Бетономешалка заливает фундамент.
4. Самосвал привозит кирпичи, окна и двери. Стены вырастают сами.
5. Самосвал привозит крышу.
6. Кран ставит крышу.
7. Экскаватор копает траншею.
8. Самосвал привозит трубы.
9. Кран кладёт трубы.
10. Каток закатывает дорожку.

## Локально

Сборка не нужна. Из папки репозитория:

```bash
python3 -m http.server 8765
```

Потом открыть http://127.0.0.1:8765/

Вся презентация — один файл `preview/index.html`: сцена, стили и логика. Картинки нарисованы в SVG.

Android-игра в этот репозиторий не входит.
